# Krom QuestHoard

Tracks the items your current quests need, so you know what to keep.

- Popup list of quest items with have/need counts
- Item tooltips tagged "KEEP" when a quest needs them
- Chat ping when you loot a tracked item

## Install (WowUp)

1. In WowUp, select your WoW install (Forever or Classic Era).
2. **Get Addons → Install from URL**, paste this repo's link, install.
3. Restart the game. Updates show up in WowUp automatically.

## Commands

- `/qh` toggle the list
- `/qh lock` lock/unlock the window
- `/qh reset` reset the window position
